# PersonalOS Offsite Backups

PersonalOS Offsite Backups is a private, personal-use backup utility. It copies selected completed backup exports into its owner's Google Drive and verifies downloaded copies during recovery checks. It uses rclone with client-side encryption for backup contents and names.

It is not a public service and has no signup. This website contains documentation only and never receives backup contents, Google OAuth tokens, or encryption keys.
